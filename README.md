# OpenAD SDK

**Author**: Vincent

Welcome to the **OpenAD SDK** repository. This repository contains the low-level JS SDK implementations for OpenAD targeting various social and gaming mini-app platforms, specifically Telegram and LINE.

🌍 English | [简体中文](README.ZH.md) | [日本語](README.JA.md)

> [!IMPORTANT]
> **Notice on Core Business Logic Omission**  
> For business security and protocol compliance, the core proprietary business logic has been stripped/omitted from this open-source repository (including but not limited to compilation and organization rules for key parameters, security verification algorithms, and low-level encrypted data reporting).
> This repository mainly preserves and demonstrates the overall workflow lifecycle management, DOM ad container rendering, and callback hooks to serve as a technical reference and starting point for developer customization.

## 🌟 Platform Certification & Performance

* **Telegram Official Certification**: The Telegram platform SDK implementation has successfully passed official security and performance audits by Telegram.
* **Massive DAU Scaling**: In live production environments, this SDK demonstrates extreme reliability, stably serving up to **450 million DAU (Daily Active Users)** with massive concurrency.
