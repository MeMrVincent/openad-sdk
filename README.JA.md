# OpenAD SDK (日本語)

**著者**: Vincent

ようこそ **OpenAD SDK** ソースコードリポジトリへ。本リポジトリには、Telegram および LINE などのソーシャル・ミニゲームプラットフォーム向け OpenAD 低レイヤ JS SDK のコア実装が含まれています。

## 🌟 プラットフォーム認定と稼働実績

* **Telegram 公式認定**：本リポジトリの Telegram 向け SDK 実装は、**Telegram プラットフォームによる公式のセキュリティおよび性能監査に合格しています**。
* **大規模な DAU のサポート**：実際の商用環境において本 SDK は極めて高い堅牢性を示しており、**1日あたり最大 4.5 億 DAU（アクティブユーザー数）の超大規模な同時アクセス**を安定して処理しています。
